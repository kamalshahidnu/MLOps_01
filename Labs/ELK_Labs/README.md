# ELK Labs

This directory contains ELK (Elasticsearch, Logstash, Kibana) stack labs for ML model monitoring and logging.

## Labs Included

1. **[Lab2_ELK_Setup_Mac](Lab2_ELK_Setup_Mac/)** - ELK stack setup on macOS for monitoring ML model predictions and metrics
   - **Model**: Random Forest Classifier for Wine Quality prediction
   - **Features**: Structured JSON logging, real-time monitoring, Kibana dashboards
   - **Platform**: macOS with Homebrew installation

## Overview

ELK stack provides a powerful solution for:
- **Logging**: Structured JSON logs of model predictions, training metrics, and errors
- **Searching**: Full-text search across all model events
- **Visualization**: Real-time dashboards for model performance monitoring
- **Alerting**: Set up alerts for model degradation or errors
